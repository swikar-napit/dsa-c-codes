## ⚙️ How to run

Each file is a standalone C program. Compile and run using GCC:

```bash
gcc BubbleSort.c -o bubblesort
./bubblesort
```

On Windows (with MinGW):

```bash
gcc BubbleSort.c -o bubblesort.exe
bubblesort.exe
```
